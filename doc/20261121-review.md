## 3. 実施した修正内容

### 3.1 JSON-RPC 2.0 / LSP ライフサイクル・エラー応答（#1〜#5）
- **対象ファイル**: [LspMessageWriter.cs](file:///D:/wsgit/UnityCSharpFastLSP/src/UnityCSharpFastLSP.Protocol/LspMessageWriter.cs), [LspServer.cs](file:///D:/wsgit/UnityCSharpFastLSP/src/UnityCSharpFastLSP.Server/LspServer.cs)
- **修正内容**:
  1. `LspMessageWriter` に `JsonRpcErrorCode` 定数と `WriteError(object? id, int code, string message)` を実装。
  2. `LspServer.HandleMessage` 内で `JsonDocument.Parse` を try-catch し、パース失敗時は `ParseError` (-32700) を `id: null` で即座に返却。
  3. `Dispatch` 処理を新設し、初期化前リクエスト（`initialize`, `shutdown` を除く）に `ServerNotInitialized` (-32002)、shutdown 後のリクエストに `InvalidRequest` (-32600) を返却。
  4. 未知のメソッド（`default`）に対して `id` がある場合は `MethodNotFound` (-32601) を返却し、通知（`id` なし）にはサイレントに応答しない仕様に準拠。

### 3.2 references の `includeDeclaration=false` 除外（#6）
- **対象ファイル**: [ScopedResolver.cs](file:///D:/wsgit/UnityCSharpFastLSP/src/UnityCSharpFastLSP.Semantics/ScopedResolver.cs)
- **修正内容**:
  - `model.Index.FindDefinitions(word)` および `ResolveScopedDefinition` で得られる宣言箇所の位置集合（URI および行・列）を収集。
  - `includeDeclaration == false` の場合、テキスト全一致走査でヒットした位置が宣言箇所と一致すればスキップするようフィルタを追加。

### 3.3 formatting 範囲補正と改行コード維持（#7, #8）
- **対象ファイル**: [FastFormatter.cs](file:///D:/wsgit/UnityCSharpFastLSP/src/UnityCSharpFastLSP.Syntax/FastFormatter.cs)
- **修正内容**:
  1. `lines.Length - 1` を終端行とすることで、末尾改行文書において存在しない行を指す問題を解消。
  2. 文書中に `"\r\n"` が存在するかを検知し（`source.Contains("\r\n") ? "\r\n" : "\n"`）、整形後のインデント改行および末尾改行に同一の改行コードを適用。
